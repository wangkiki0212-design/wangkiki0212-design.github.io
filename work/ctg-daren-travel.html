CASE 06 / 品牌全案PROPOSAL CASE

CTG CREATOR TRAVEL PROGRAM

中旅集团「达人中旅行」年度项目营销策划

围绕中国旅游集团多产业资源，规划贯穿全年的达人内容 IP，把热点、创作者与集团旅行产品组织成可持续内容机制。

CLIENT
中国旅游集团
PERIOD
2025 年度提案
ROLE
年度投标方案/ 品牌自造节/ 达人生态/全链路传播
01 / CONCEPT

方案构思

项目背景与命题

集团同时运营旅行社、酒店、邮轮、免税与目的地等多类资源，却缺少一个既能聚合品牌、又能持续产出平台内容的年度命题。内容因此容易停留在单点项目，难以形成积累。

关键洞察

用户理解一个大型旅游集团，不是通过业务清单，而是通过一次次具体、可信、可跟随的旅行体验。因此年度命题需要落在一个能被体验的视角上。

02 / STRATEGY

方案策略

以「达人中旅行」为内容母体，通过热点共创、达人内容、用户互动与种草影响，把集团的多业务场景组织成一套可以持续运转的内容机制。

01

年度内容 IP

围绕热点与季节节点拆分四类内容章节，形成全年连续叙事，让每次投放都在为同一个 IP 累积认知。

02

达人生态

按头部、垂类与 KOC 组织创作者角色，让影响力与内容密度互补，覆盖从认知到决策的不同阶段。

03

产业联动

让邮轮、酒店、免税、旅行社和目的地产品进入同一内容入口，把分散资源变成可被一次讲清的整体。

SCOPE / 规划范围

05 / MY POSITION

我在其中的定位

负责盘点集团业务与传播资源，设计年度内容 IP 架构，规划创作者分层与合作机制，并拆解四个季度的内容节奏。

具体职责 / WHAT I DID

  2. 02设计年度内容 IP 架构
  3. 03规划创作者分层与合作机制
  4. 04拆解四章季度内容节奏
