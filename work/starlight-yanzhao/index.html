CASE 07 / 品牌全案PROPOSAL CASE

STARLIGHT YANZHAO TRAIN LAUNCH

中旅集团 — 星光列车燕赵号首发营销策划

把旅游列车从交通产品转译为可被想象的慢旅行体验，用首发事件、创作者第一视角与长尾种草建立新品认知。

CLIENT
河北文旅 · 星光燕赵号
PERIOD
2025 首发提案
ROLE
小预算高转化 / 达人矩阵 / 视频+直播+团购全链路
01 / CONCEPT

方案构思

项目背景与命题

旅游列车是一个全新产品，需要在有限的传播周期内，同时完成产品解释、品牌背书、内容扩散与购买意愿建立。四件事缺一件，新品就难以被真正理解。

关键洞察

列车旅行的吸引力不只在路线，而在沿途体验、车厢社交与慢旅行仪式感共同构成的内容产品。要卖的不是一张票，而是一段可以被想象的旅程。

02 / STRATEGY

方案策略

以首发事件制造声量高峰，匹配旅行与内容创作者完成第一批体验解释，再用长尾内容持续消除理解门槛。

01

首发事件

让路线、车厢体验与服务亮点在同一场内容事件中被集中看见，一次性完成新品的产品解释。

02

创作者体验

规划 1 位头部创作者担任「一日列车长」，由 2 位垂类达人与 20 位本地团购达人补足体验内容与交易内容。

03

长尾种草

首发之后持续释放沿途玩法、目的地内容与产品购买信息，让后续决策随时能找到答案。

SCOPE / 规划范围

执行结果数据

该项目仍处于提案阶段，没有可核验的执行结果。以下只呈现方案中规划的数量与范围。

013 阶段首发、引爆、长尾
021 场首发内容事件
032 位垂类内容达人规划
0420 位本地团购达人规划

口径说明：以上为方案规划的目标与范围，项目尚未执行，不构成实际成果。

04 / VISUAL ARCHIVE

图片展示区域

图片来自 星光燕赵号首发传播方案。普通图片按编辑画册编排，竖版手机截图使用独立内容序列，避免强行裁切。

VISUAL ARCHIVE / 图片展示区域

图片来自 星光燕赵号首发传播方案

05 / MY POSITION

我在其中的定位

提炼列车产品的传播卖点，设计首发与长尾的内容节奏，规划 KOL / KOC 分层合作，并建立从曝光到交易的指标路径。

具体职责 / WHAT I DID

  1. 01提炼列车产品传播卖点
  2. 02设计首发与长尾内容节奏
  3. 03规划 KOL / KOC 分层合作
  4. 04建立曝光到交易的指标路径
项目说明 / NOTE

这是首发提案方案，不展示预测成果。价值在于把一次产品发布，组织成一套可以持续解释产品的内容系统。
